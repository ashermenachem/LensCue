# Security

Please do not publish credentials, private scripts or audio in an issue. For a suspected vulnerability that could expose users' data, use **Security → Report a vulnerability** on GitHub if private reporting is available, or contact the maintainer privately through their GitHub profile. General defects belong in Issues.

The v1.0 release is ad-hoc signed and not Apple-notarized. Download only from this repository's Releases, or build the source yourself. We do not currently promise a response time or a supported-version security-maintenance schedule.
