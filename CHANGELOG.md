# Changelog

## 1.0.0 — 2026-11-01

First public release.

- A black, rounded overlay visually connected to the Mac camera notch, with its reading line six points below the cutout.
- On-device English word following, voice activity and steady auto-scroll.
- Hover-to-pause, manual scrolling, click-to-resume and restart controls.
- Local script editor, UTF-8 text import, autosave and adjustable overlay dimensions.
- Menu bar controls, app icon, keyboard shortcuts and complete MIT-licensed source.

The downloadable build targets Apple silicon and macOS 14+. It is ad-hoc signed, not Apple-notarized. Word following is English-only. Screen-capture invisibility is not guaranteed.
