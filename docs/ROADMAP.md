# Roadmap

[← Back to LensCue](../README.md)

LensCue should stay small and easy to use. These are directions for future work, not release promises.

## Available in 1.0

- [x] Notch-connected black overlay
- [x] On-device English word following
- [x] Voice activity and steady auto-scroll modes
- [x] Hover pause, manual scroll and click-to-resume
- [x] Local script and display preferences
- [x] Free Apple silicon download and complete MIT-licensed source

## Next to explore

- [ ] More testing with different microphones, accents and long scripts
- [ ] A clearer on-device language-model setup flow
- [ ] Robust recovery after microphone disconnection or recognition interruptions
- [ ] Validated Intel builds
- [ ] Multiple local scripts and export
- [ ] Optional display selection and compact layout presets
- [ ] Accessibility improvements and configurable shortcuts
- [ ] Developer ID signing and Apple notarization, if project resources allow

Discuss an idea in [Discussions](https://github.com/ashermenachem/LensCue/discussions). Reproducible bugs belong in [Issues](https://github.com/ashermenachem/LensCue/issues/new/choose).
